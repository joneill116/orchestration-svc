# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please follow the responsible disclosure process:

1. Do not open a public issue. Instead, email the maintainers at [your.email@example.com] with details.
2. We will acknowledge receipt within 2 business days and coordinate a fix.
3. Once resolved, we will publish a security advisory and credit the reporter (if desired).

## Supply Chain
- All dependencies are continuously audited with pip-audit.
- SBOMs are generated for every release.
- No secrets are ever committed to the repository.

## Supported Versions
- Only the latest release is supported for security patches.
